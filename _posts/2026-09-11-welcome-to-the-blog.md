This is the first post. It's written in plain markdown, so headings, **bold**, _italics_, links, and lists all work as you'd expect.

Images work too — just drop a file into `assets/images/` and reference it:

![An example image](/assets/images/example.svg)

To write a new post, add a file to `_posts/` named `YYYY-MM-DD-title.md` with a front matter block like the one at the top of this file, then write your content below it in markdown.
